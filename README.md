Personal Portfolio Website:
- About the Project:
- This is a personal portfolio website created using HTML, CSS, and JavaScript. The purpose of this website is to introduce myself, showcase my achievements, and keep my projects and certificates in one place.
The website includes information about my education, interests, extracurricular activities, and skills. It also has sections for photographs and videos from Scouts and Guides and Junior Red Cross activities.
- Features:
1.	Personal introduction and profile photo
2.	Education and skills section
3.	Projects and achievements
4.	Photo and video gallery
5.	Certificates section
6.	Interactive buttons and navigation
7.	Responsive design for desktop and mobile devices
- Technologies Used:
1.	HTML – to create the structure of the website
2.	CSS – to style the pages and make the layout responsive
3.	JavaScript – to add interactive features
- How to Run the Website:
1.	Download or clone this repository.
2.	Extract the files if downloaded as a ZIP.
3.	Open the project folder.
4.	Open index.html in a web browser.
5. No additional software is required to view the website.
- Deployment:
The website can be hosted using GitHub Pages.
To publish it, open the repository on GitHub, go to Settings → Pages, select the main branch and the root folder, and save the settings.
Project Purpose:
I created this website to learn the basics of web development and present my personal information, activities, and achievements in an organised way.
